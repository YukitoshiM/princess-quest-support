サポート / Support

個人情報を送らないでください。
お問い合わせには、お子さまの本名、写真、住所、学校名などを書かないでください。
Do not send a child's legal name, photos, address, school, or other personal information.

まず確認すること / First steps

アプリを終了してもう一度開き、iPhoneとiCloudの空き容量、通信状態、Apple Accountへのサインインを確認してください。iCloudを使えない場合も、端末内の基本機能は利用できます。

Quit and reopen the app, then check available iPhone and iCloud storage, network access, and Apple Account sign-in. Core on-device features remain available without iCloud.

データを削除したい / Delete data

保護者画面の「データの保存」を開き、「iCloudのコピーだけ削除」または「すべての家族データを削除」を選んでください。削除前に対象と影響を表示します。

Open Data Storage in the parent area and choose Delete iCloud Copy or Delete All Family Data. The app shows the affected data before deletion.

不具合の報告 / Report a problem

公開前はTestFlightの「ベータ版フィードバックを送信」を利用できます。GitHubアカウントをお持ちの場合は、下のフォームから報告できます。

Before public release, you can use Send Beta Feedback in TestFlight. If you have a GitHub account, you can also use the form below.
